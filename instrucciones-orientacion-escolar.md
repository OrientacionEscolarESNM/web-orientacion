# Instrucciones para desarrollar la web de Orientación Escolar

## Contexto del proyecto

Desarrollar un **boceto inicial de alta calidad visual y funcional** para la web del área de **Orientación Escolar** de la **Institución Educativa Escuela Normal Superior de Monterrey**. El objetivo no es hacer una página genérica de “servicio escolar”, sino una experiencia web moderna, cálida, humana y pedagógica, con una presencia institucional fuerte y una sensación clara de acompañamiento, cuidado, confianza y dirección.[cite:31][cite:1][cite:21]

La web debe comunicar que Orientación Escolar es un espacio de apoyo integral para **estudiantes, familias y docentes**, con énfasis en bienestar, convivencia, inclusión, proyecto de vida, prevención, seguimiento y activación de rutas cuando corresponda.[cite:1][cite:3][cite:21]

La responsable visible del área es **Katherine Ponce**, **Terapeuta Ocupacional, Magíster en Neuropsicología y Educación**. Los datos de contacto que deben aparecer de forma visible son: **WhatsApp 3214637057** y **orientacionescolar@normalsuperiormonterrey.com**. Estos datos fueron suministrados para este proyecto y deben integrarse de forma elegante y útil en la interfaz.

## Referente y meta de mejora

Existe un referente previo desarrollado para otra dependencia: [web del Consejo de Padres](https://consejopadresensm.github.io/web-consejo-de-padres/index.html). Este nuevo proyecto debe tomar esa experiencia como punto de partida conceptual, pero superarla claramente en:

- identidad visual,
- jerarquía de información,
- usabilidad móvil,
- modularidad del contenido,
- dinamismo del hero,
- accesibilidad,
- integración con Google Sheets,
- sensación institucional y emocional.

La expectativa es una web “mucho mejor”: más contemporánea, más limpia, más emocional, más navegable y más fácil de mantener.

## Objetivo narrativo y emocional

La primera impresión del sitio debe transmitir algo muy específico: **aquí hay acompañamiento real**. No debe parecer una página fría administrativa ni una landing genérica de colegio. Debe sentirse como un lugar confiable, protector y orientador.[cite:1][cite:3]

La dirección emocional deseada combina estos conceptos:

- confianza,
- escucha,
- guía,
- bienestar,
- esperanza,
- desarrollo,
- cuidado,
- comunidad,
- pedagogía,
- humanidad.

La sensación general debe ser: “este espacio me recibe, me orienta y me acompaña”.

## Idea visual del hero principal

El primer bloque visible de la web debe ser muy potente. No basta con un banner estático con texto encima. Debe existir un hero con **fuerza simbólica y emocional**.

### Propuesta conceptual del hero

Construir un encabezado principal que represente el acto de orientar, acompañar y abrir caminos. Algunas metáforas visuales posibles:

- una ruta luminosa o sendero abstracto que atraviesa formas suaves y conduce hacia un horizonte;
- figuras humanas abstractas conectadas por líneas orgánicas, simbolizando apoyo y red;
- un amanecer o expansión de luz detrás de una composición pedagógica e institucional;
- capas de formas fluidas que evoquen crecimiento emocional, escucha y contención;
- un árbol de trayectorias, donde cada rama represente desarrollo, proyecto de vida y acompañamiento;
- un universo visual sutil que combine cuaderno, conversación, camino, mente y comunidad, sin verse infantil.

### Lineamientos visuales del hero

- Debe verse **moderno y editorial**, no escolar-infantil.
- Debe evitar fotos genéricas de stock de niños sonriendo.
- Si se usa imagen o ilustración, debe ser **artística, cálida y simbólica**.
- Puede usarse una composición híbrida: fondo abstracto + siluetas/figuras + texto institucional.
- Debe incluir microanimaciones suaves: desplazamiento de capas, aparición gradual, brillos sutiles, movimiento de partículas o líneas muy discretas.
- La animación debe aportar vida, no distraer.
- Debe haber versión móvil impecable.

## Dirección de diseño

La web debe sentirse contemporánea, profesional y cercana. La referencia estética ideal está entre una web institucional moderna, un proyecto editorial humano y una interfaz cultural cuidada.

### Personalidad visual

- Institucional pero no rígida.
- Emocional pero no cursi.
- Moderna pero no futurista.
- Cálida pero no recargada.
- Clara pero no plana.

### Paleta sugerida

Construir una paleta sobria, accesible y con sensibilidad pedagógica. Sugerencia inicial:

- Base clara cálida: marfil, crema, beige humo o blanco roto.
- Texto principal: gris carbón suave.
- Color primario: verde petróleo, teal profundo o azul verdoso sereno, por su asociación con calma, confianza y equilibrio.
- Color secundario de apoyo: dorado suave, terracota leve o coral apagado, para pequeños acentos humanos.
- Color de apoyo suave: verde salvia o azul niebla para fondos secundarios.

Evitar:

- gradientes morado-azul típicos de plantillas IA,
- saturación excesiva,
- demasiados colores en una misma pantalla,
- efectos “tech”.

### Tipografía sugerida

Usar una combinación intencional de dos familias tipográficas:

- una fuente con personalidad para titulares, preferiblemente elegante y humana;
- una sans serif muy legible para cuerpo, navegación y componentes.

Posibles combinaciones:

- Instrument Serif + Inter,
- Boska + Satoshi,
- Zodiak + General Sans,
- Source Serif 4 + Manrope.

La idea es que los títulos tengan sensibilidad y presencia, mientras que el cuerpo mantenga claridad, limpieza y buen rendimiento móvil.

## Arquitectura del contenido

La web debe construirse desde el inicio con una arquitectura preparada para crecer y para administrar contenido desde Google Sheets.

### Navegación principal sugerida

- Inicio
- El área
- Actividades
- Campañas
- Comunicados
- Recursos
- Rutas de atención
- Normatividad
- Contacto

### Estructura general recomendada

#### 1. Inicio

Debe incluir:

- hero principal;
- resumen institucional del área;
- accesos rápidos a rutas, recursos y contacto;
- actividades destacadas;
- campañas activas;
- últimos comunicados;
- recursos destacados por público;
- bloque de confianza con enfoque, valores y acompañamiento;
- CTA final de contacto.

#### 2. El área

Contenido:

- quiénes somos;
- misión;
- visión;
- objetivo general;
- objetivos específicos;
- principios del servicio;
- perfil profesional de Katherine Ponce;
- enfoque de atención;
- alcance y límites del servicio.

Importante: el texto debe dejar claro que Orientación Escolar cumple una función pedagógica e institucional, no sustituye atención clínica externa y activa rutas o remisiones cuando corresponde.[cite:16][cite:20]

#### 3. Actividades

Esta sección debe pensarse como una agenda viva o repositorio de acciones desarrolladas por el área. Las actividades pueden ser talleres, charlas, encuentros, jornadas, intervenciones, conmemoraciones, espacios formativos o acciones preventivas.

Cada actividad idealmente debe tener:

- título,
- fecha,
- hora,
- lugar,
- público objetivo,
- descripción,
- campaña relacionada,
- imágenes,
- archivos adjuntos,
- estado: próxima, en curso, realizada,
- destacado sí/no.

La visualización puede ser en forma de:

- tarjetas filtrables,
- línea de tiempo,
- calendario visual,
- carrusel de destacadas.

#### 4. Campañas

Las campañas son una capa superior organizativa que agrupa actividades y contenidos. Ejemplos: convivencia escolar, salud mental, proyecto de vida, prevención de violencias, inclusión, escuela de familias.[cite:1][cite:21]

Cada campaña debería tener:

- nombre,
- subtítulo,
- propósito,
- periodo,
- color/acento visual,
- imagen o ilustración,
- descripción larga,
- actividades relacionadas,
- recursos asociados,
- comunicados relacionados,
- estado: activa/inactiva.

En la web, las campañas deben sentirse como narrativas temáticas, no solo como categorías administrativas.

#### 5. Comunicados

Sección pensada para noticias breves, avisos, anuncios institucionales, invitaciones o publicaciones oficiales del área.

Cada comunicado puede incluir:

- título,
- fecha,
- resumen,
- cuerpo,
- imagen de portada,
- archivos,
- categoría,
- público objetivo,
- enlace externo opcional,
- destacado sí/no.

Visualmente deben verse como piezas editoriales limpias.

#### 6. Recursos

Esta es una sección crucial. Debe estar organizada por audiencia y por tipo de material.

Subsecciones sugeridas:

- Para estudiantes
- Para familias
- Para docentes

Filtros sugeridos:

- documentos,
- videos,
- imágenes,
- guías,
- infografías,
- formatos,
- enlaces externos.

Cada recurso debería tener:

- título,
- descripción,
- audiencia,
- tipo,
- campaña relacionada,
- miniatura,
- archivo o enlace,
- fecha,
- etiquetas,
- destacado sí/no.

#### 7. Rutas de atención

Debe ser una sección muy visible, clara y pedagógica. No debe verse legalista ni intimidante. Debe explicar de manera simple cuándo acudir, cómo se atiende y qué pasos puede seguir la institución según el caso.[cite:21][cite:23]

Subbloques sugeridos:

- cuándo acudir al área;
- convivencia escolar;
- vulneración de derechos;
- salud mental y bienestar emocional;
- presunto consumo de SPA;
- remisión externa;
- preguntas frecuentes.

#### 8. Normatividad

Debe incluir una versión resumida, comprensible y visual de las normas base. No copiar leyes completas. Explicar por qué sustentan el área.[cite:10][cite:21][cite:1][cite:16]

Normas clave a mostrar:

- Ley 115 de 1994;
- Ley 1620 de 2013;
- Plan Nacional de Orientación Escolar;
- Resolución 3842 de 2022;
- Manual de Convivencia institucional.[cite:10][cite:21][cite:1][cite:16]

#### 9. Contacto

Debe incluir:

- perfil breve de la orientadora;
- WhatsApp;
- correo;
- horarios si luego se definen;
- formulario opcional;
- llamada a la acción humana y tranquila.

### Recomendaciones técnicas para Claude

- Separar una capa `data` o `services` para el consumo de Sheets.
- Crear un parser robusto que convierta filas a objetos limpios.
- Manejar campos vacíos, booleanos y listas separadas por comas.
- Permitir fallback local con archivos JSON si falla la hoja.
- Diseñar componentes que se alimenten por colección: campañas, actividades, comunicados, recursos.
- Dejar preparada una función para filtrar por audiencia, campaña, categoría o destacado.

## Recomendaciones de experiencia de usuario

### Inicio con bloques vivos

La home no debe ser un muro de texto. Debe estar compuesta por bloques visuales, respirados y variados.

Sugerencia de secuencia:

1. Hero emocional.
2. Accesos rápidos.
3. Presentación del área.
4. Campañas destacadas.
5. Próximas actividades.
6. Últimos comunicados.
7. Recursos por audiencia.
8. Rutas de atención.
9. Bloque de confianza o acompañamiento.
10. Contacto final.

### Componentes deseables

- tarjetas elegantes para actividades;
- tarjetas editoriales para comunicados;
- badges por audiencia;
- filtros visuales suaves;
- acordeones elegantes en preguntas frecuentes;
- línea de tiempo o calendario ligero para actividades;
- chips para etiquetas y categorías;
- botones con hover muy fino;
- bloques destacados con frases institucionales.

### Microinteracciones

- apariciones suaves al hacer scroll;
- hover delicado en tarjetas;
- transición sutil en botones;
- cambio de estado agradable en filtros;
- hero con animación ambiental casi imperceptible;
- tema claro/oscuro opcional solo si se implementa bien.

## Sugerencia técnica de stack

Si se va a desarrollar localmente y luego desplegar de manera simple, una buena opción es:

- HTML/CSS/JS bien estructurado si se quiere máxima simpleza;

- consumo de datos desde Google Sheets vía JSON;
- despliegue posterior en GitHub Pages o hosting estático.

Si se prioriza mantenimiento fácil, el proyecto debe ser estático y desacoplado del contenido.
